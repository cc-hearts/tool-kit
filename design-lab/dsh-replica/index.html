  1. bg/grid-paper

    核心

    28px 方格纸底纹：两道 1px linear-gradient 叠加，线色取自 --paper-2，比背景深一档，只在 Hero 区出现。
    背景底纹
    用法 ▾
    CSS

  2. bg/warm-paper

    核心

    不用纯白 #fff，用暖白 #f6f2ea；深色不用纯黑，用暖黑 #211d18。整体偏纸感，降低屏幕冷光。
    背景底纹

  3. bg/cinnabar-accent

    核心

    朱砂红 #c0392b 是唯一强调色：h1 里的 em、星标、聚焦投影、按钮。克制到全屏只有几处。
    背景底纹

  4. nav/sticky-glass

    顶部

    导航栏 sticky 吸附 + backdrop-filter:blur(10px) 毛玻璃，底色用 color-mix 把纸色降到 90% 透明。
    顶部导航
    用法 ▾
    CSS

  5. nav/pixel-logo

    顶部

    像素方块 logo：8 个圆角方块组成 L 形，加一块旋转 9° 的朱砂方块，进场时从右上「啪」地吸附到位。
    顶部导航

  6. nav/offset-shadow

    顶部

    搜索框用 3px 3px 0 的零模糊硬投影，聚焦时投影从纸灰变成朱砂红。轻微的复古印刷感。
    顶部导航
    用法 ▾
    CSS

  7. nav/ink-border

    顶部

    搜索框边框用 1.5px 实心墨色（而非灰），配合硬投影形成「描边 + 投影」的双层轮廓。
    顶部导航

  8. card/hover-lift

    卡片

    卡片 hover 上浮 2px，阴影从无到双层（近处 5% + 远处 8%），圆角 14px，边框从 --line 过渡到 --line-2。
    卡片

  9. card/pill-chip

    卡片

    筛选 chip 全圆角 999px，选中态直接反色：墨色底 + 纸色字，不用朱砂，避免强调色泛滥。
    卡片

  10. card/mono-metrics

    卡片

    星标、下载量、计数等数字统一用等宽字体 + tabular-nums，保证数字对齐不跳动。
    卡片

  11. token/semantic-tokens

    令牌

    paper / ink / line / cinnabar 四组语义令牌，深浅色只换值不换名，组件层零改动。
    设计令牌

  12. token/archivo-display

    令牌

    标题用 Archivo 800 + letter-spacing -0.03em，正文用 Inter，代码用等宽。字体三层分工明确。
    设计令牌

设计令牌

/* 浅色 · 宣纸 */
--paper:#f6f2ea;  --paper-2:#efe9dd;
--card:#fffdf8;   --line:#e0d8c8;
--ink:#2b2620;    --ink-2:#5f574a;
--cinnabar:#c0392b;

/* 深色 · 暖黑 */
--paper:#211d18;  --paper-2:#282218;
--card:#2a2620;   --line:#3b352c;
--ink:#ece7de;    --ink-2:#b5ac9e;
--cinnabar:#e06a52;

深色下朱砂要提亮到 #e06a52，否则在暖黑底上会发闷。

方格纸底纹

/* 两道 1px 渐变叠加成网格 */
header.hero{
  background-image:
    linear-gradient(var(--paper-2) 1px,transparent 1px),
    linear-gradient(90deg,var(--paper-2) 1px,transparent 1px);
  background-size:28px 28px;
  border-bottom:1px solid var(--line);
}

线色只比底色深一档，远看是纸纹，近看才是格。格子只在 Hero 区出现，正文区保持干净。
